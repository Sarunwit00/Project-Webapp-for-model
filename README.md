# เว็บแปลงเสียงภาษาถิ่นเป็นข้อความภาษาไทย

เว็บแอปที่อัดเสียงจากไมค์หรืออัปโหลดไฟล์เสียง แล้วถอดออกมาเป็นข้อความภาษาไทย
ด้วยโมเดล **Wav2Vec2** ที่ fine-tune เอง พร้อมระบบให้ผู้ใช้เสนอประโยคใหม่
และหน้าผู้ดูแลสำหรับตรวจและส่งออกข้อมูลที่เก็บมาเป็นชุดข้อมูลสำหรับเทรนรอบถัดไป

## ความสามารถ

**หน้าถอดเสียง**

- อัดเสียงจากไมโครโฟน พร้อมแถบวัดระดับเสียงขณะอัด
- อัปโหลดไฟล์เสียงที่มีอยู่แล้ว
- แปลงเสียงเป็น WAV 16kHz **ในเบราว์เซอร์** ก่อนส่งขึ้นเซิร์ฟเวอร์ ทำให้ฝั่งเซิร์ฟเวอร์ไม่ต้องติดตั้ง ffmpeg
- อ่านผลลัพธ์ออกเสียงได้ด้วย speech synthesis ของเบราว์เซอร์
- ตรวจจับผลลัพธ์ที่เชื่อถือไม่ได้ เช่นกรณีโมเดลพ่นตัวอักษรซ้ำ ๆ ออกมาเพราะเสียงไม่ตรงกับที่เทรนไว้
  แล้วบอกผู้ใช้ตรง ๆ แทนที่จะโชว์ข้อความมั่ว ๆ
- แยกข้อความแจ้งเตือนตามสาเหตุ เช่นแทบไม่มีเสียงเข้าไมค์ ติดต่อเซิร์ฟเวอร์ไม่ได้ หรือได้ยินเสียงแต่ถอดไม่ออก

**ระบบเสนอประโยค**

- ผู้ใช้เสนอประโยคใหม่พร้อมไฟล์เสียงเข้ามาได้ เพื่อเอาไปขยายชุดข้อมูล
- เก็บลง SQLite พร้อมไฟล์เสียงที่แนบมา

**หน้าผู้ดูแล**

- ล็อกอินก่อนเข้าใช้
- ตารางรายการที่ผู้ใช้เสนอเข้ามา พร้อมตัวกรอง
- อนุมัติ ปฏิเสธ หรือลบทีละรายการ
- ฟังเสียงที่แนบมาได้
- ส่งออกเป็น CSV, ZIP หรือ **ชุดข้อมูลพร้อมเทรน** (`/suggest/export_dataset.zip`)

## เทคโนโลยีที่ใช้

| ส่วน | ใช้อะไร |
|---|---|
| หน้าเว็บ | React 18, Vite 6, Web Audio API, MediaRecorder, SpeechSynthesis |
| เซิร์ฟเวอร์ | Python, FastAPI, Uvicorn |
| โมเดล | PyTorch, Hugging Face Transformers (`Wav2Vec2ForCTC`) |
| ฐานข้อมูล | SQLite |

## โครงสร้าง

```
WebAppProject/
└─ Web/
   ├─ frontend-react/      หน้าเว็บ React (Vite) — มี 2 หน้า คือหน้าถอดเสียงกับหน้าผู้ดูแล
   │  └─ src/
   │     ├─ App.jsx           state กลาง + ฟังก์ชันถอดเสียงที่ใช้ร่วมกัน
   │     ├─ AdminApp.jsx      หน้าผู้ดูแล
   │     ├─ components/       ส่วนอัดเสียง อัปโหลด ผลลัพธ์ เสนอประโยค
   │     ├─ hooks/            useRecorder (อัดเสียง), useSpeech (อ่านออกเสียง)
   │     └─ lib/              audio.js แปลงเป็น WAV 16kHz, api.js เรียก backend
   └─ server/
      ├─ app.py              เซิร์ฟเวอร์ FastAPI + เสิร์ฟไฟล์ที่ build แล้วของ React
      ├─ requirements.txt
      ├─ run.bat             ดับเบิลคลิกเพื่อ build React แล้วเปิดเซิร์ฟเวอร์
      └─ share.bat           เปิดลิงก์สาธารณะชั่วคราวผ่าน Cloudflare Tunnel
```

โฟลเดอร์โมเดลอยู่**นอก** repo นี้ (ค่าเริ่มต้นคือ `Desktop/Model/`)
เปลี่ยนที่อยู่ได้ด้วย environment variable `MODEL_DIR`

## วิธีรัน

ง่ายสุดคือดับเบิลคลิก **`Web/server/run.bat`** สคริปต์จะสร้าง virtual environment
ติดตั้ง dependencies build หน้าเว็บ React แล้วเปิดเซิร์ฟเวอร์ให้ จากนั้นเปิด <http://127.0.0.1:8000>

รันเองทีละขั้นก็ได้

```bash
cd Web/server
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python -m uvicorn app:app --host 127.0.0.1 --port 8000
```

รายละเอียดเต็ม รวมถึงวิธีรัน React dev server แยกตอนพัฒนา อ่านได้ที่
[`Web/server/README.md`](Web/server/README.md) และ [`Web/frontend-react/README.md`](Web/frontend-react/README.md)

## API หลัก

| Method | Path | ทำอะไร |
|---|---|---|
| `GET` | `/health` | เช็กสถานะเซิร์ฟเวอร์ อุปกรณ์ที่ใช้ (cpu/cuda) และที่อยู่โมเดล |
| `POST` | `/transcribe` | รับไฟล์ WAV 16kHz mono แล้วคืนข้อความที่ถอดได้ |
| `POST` | `/suggest` | รับประโยคใหม่พร้อมไฟล์เสียงที่ผู้ใช้เสนอเข้ามา |
| `GET` | `/suggest/count` | จำนวนประโยคที่เสนอเข้ามาทั้งหมด |

นอกจากนี้ยังมีกลุ่ม endpoint สำหรับผู้ดูแลที่ต้องล็อกอินก่อน ใช้จัดการและส่งออกข้อมูล
ดูรายการทั้งหมดได้ที่ `/docs` ตอนเซิร์ฟเวอร์เปิดอยู่

## ข้อควรรู้

- ต้องมีโฟลเดอร์โมเดลแยกต่างหาก repo นี้ไม่ได้เก็บไฟล์โมเดลไว้
- ติดตั้งครั้งแรกจะดาวน์โหลดประมาณ 1GB เพราะมี PyTorch
- รันบน CPU ได้ ถ้าเครื่องมี GPU และ CUDA จะใช้ GPU ให้อัตโนมัติ
- `share.bat` เปิดลิงก์สาธารณะได้เฉพาะตอนเครื่องเปิดและเซิร์ฟเวอร์รันอยู่
  และลิงก์เปลี่ยนใหม่ทุกครั้ง เหมาะกับโชว์งานหรือทดสอบ ไม่ใช่ใช้งานจริงตลอดเวลา
